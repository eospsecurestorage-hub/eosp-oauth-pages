EOSP rclone — Storage Integration

EOSP rclone is a private storage integration used for development and backup operations associated with the European Offline Survival Platform (EOSP) project.

It uses Google Drive authorization through OAuth 2.0 and requests the drive.file permission, allowing access to files created or explicitly opened with the application.

This integration is currently intended for use by its owner and is not offered as a public service.
